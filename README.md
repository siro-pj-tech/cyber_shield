# 🛡️ サイバー・シールド（CYBER SHIELD）：1988-2026 (v1.0)

1988年のフロッピーディスク時代から2026年のAI・ディープフェイク時代まで、時代とともに進化するサイバー攻撃から「個人情報」を守り抜くブラウザ防衛ゲームです。

## 🎮 ゲームの特徴
* **全5時代・18個の個人情報を防衛**: 1988年（PC-8801）、1999年（Windows 98・ダイヤルアップ）、2010年（公衆Wi-Fi・SNS）、2024年（スマホ・フィッシング＆ランサムウェア）、2026年（AIディープフェイク）の5つの時代を駆け抜けます。
* **くもりガラス越しの攻防**: 画面上部で迫りくる5段階の侵入ランプを見極め、制限時間内に適切な防衛コマンドを選択します。
* **適性診断システム**: 初回プレイ時の5問の適性診断により、「適性A（一般ユーザー）」または「適性B（セキュリティエンジニア）」に判定され、プロ専用の解析・迎撃コマンドが解放されます。
* **周回脅威レベル（Lv.1〜Lv.3）**: 全ステージを完全防衛クリアすると、トラップ選択肢の追加や制限時間短縮・選択肢シャッフルが加わる高難易度モード（Lv.2 / Lv.3）が解放されます。

## 🔊 サウンド・BGMについて
HTMLファイルと同じ階層に以下の2つのMP3ファイルを配置することで、オリジナルBGMが自動再生されます（効果音はWeb Audio APIにより単体で動作します）。
* `Cyber Defense Showdown (1988-2026).mp3`（ステージ中ループ再生）
* `Cyber Defense Safe Haven (Menu & Results).mp3`（オールクリア後リザルト再生）
